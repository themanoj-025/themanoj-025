Emotion-Lens, finsight-agent, Smart-Spam-Detector, and the profile-artifact
generator for `themanoj-025`). Several of these projects **use LLM/agent

specific percentage of the codebase that was written by an AI assistant.

## Known Limitations & Risks

- **AI usage of the project is not the same as AI assistance in the project.**
  These products use LLM/agent libraries at runtime; this disclosure does not
  assert that the code was AI-written.
- No transcript, export, or prompt file is stored in `docs/ai/transcripts/`.
  Raw AI chats are intentionally not tracked (they frequently contain unredacted
  content).
- Any claim of a non-zero AI-assistance share in this file is invalid until a
  concrete commit/blob/tool identity is attached.
